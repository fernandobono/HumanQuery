🔒 Privacidad Garantizada

La IA nunca tiene acceso directo a tus datos. Solo recibe el esquema de la base de datos (estructura de tablas y columnas) para generar las consultas SQL. El backend ejecuta las consultas de forma segura y solo comparte los resultados ya obtenidos con la IA para su humanización. Tus credenciales y datos sensibles permanecen protegidos en todo momento.

🤖 ¿Cómo funciona esta aplicación?

📋 Descripción

Esta API permite hacer consultas a una base de datos SQL Server usando lenguaje natural, sin necesidad de escribir SQL. La inteligencia artificial traduce tu pregunta en una consulta SQL, obtiene los resultados y los presenta de forma comprensible.

🔄 Flujo paso a paso

  1. Usuario hace una consulta en lenguaje natural
    Ejemplo: "Muéstrame los 10 productos más vendidos"
  2. Backend envía a la IA:
    La consulta del usuario y el esquema de la base de datos (solo estructura)
  3. IA devuelve una sentencia SQL
    Ejemplo: SELECT TOP 10 * FROM Products ORDER BY Sales DESC
  4. Backend ejecuta la sentencia SQL
    Se conecta de forma segura a la base de datos
  5. Base de datos devuelve resultados crudos
    Datos en formato de filas y columnas
  6. Backend envía resultados a la IA
    Solo los datos ya obtenidos (no acceso directo a la BD)
  7. IA devuelve resultados humanizados
    Transforma los datos en respuesta comprensible
  8. Usuario recibe la respuesta en lenguaje natural
