🤖 ¿Cómo funciona esta aplicación?

📋 Descripción

Esta API permite hacer consultas a una base de datos SQL Server usando lenguaje natural, sin necesidad de escribir SQL. La inteligencia artificial traduce tu pregunta en una consulta SQL, obtiene los resultados y los presenta de forma comprensible.

🔒 Privacidad y Seguridad

Importante: La IA NUNCA tiene acceso a tus datos reales. Solo recibe el esquema de la base de datos (nombres de tablas y columnas) y los resultados ya obtenidos para humanizarlos. El backend actúa como intermediario seguro.

🔄 Flujo paso a paso

  1. Usuario hace una consulta en lenguaje natural
    Ejemplo: "Muéstrame los 10 productos más vendidos"
  2. Backend envía a la IA:
    La consulta del usuario y el esquema de la base de datos (solo estructura: tablas y columnas)
  3. IA devuelve una sentencia SQL
    Ejemplo: SELECT TOP 10 * FROM Products ORDER BY Sales DESC
  4. Backend ejecuta la sentencia SQL
    Se conecta de forma segura a la base de datos y ejecuta el query generado
  5. Base de datos devuelve resultados crudos
    Datos en formato de filas y columnas
  6. Backend envía resultados crudos a la IA
    Solo los datos ya obtenidos (no acceso a la BD)
  7. IA devuelve resultados humanizados
    Transforma los datos en una respuesta comprensible
  8. Usuario recibe la respuesta en lenguaje natural

📊 Este Monitor

Este monitor muestra en tiempo real cada paso del proceso, permitiéndote ver:

  • La consulta original en lenguaje natural
  • El SQL generado por la IA
  • Los datos crudos devueltos por la base de datos
  • La respuesta humanizada final
  • Estadísticas y tiempos de ejecución
