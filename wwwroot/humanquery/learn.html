Aprende cómo funciona el sistema de consultas en lenguaje natural

¿Qué es Human Query? Principiante

Definición Simple

Human Query es un sistema que te permite hacer preguntas a una base de datos usando lenguaje natural (español o inglés), y obtener respuestas en lenguaje humano sin necesidad de saber SQL.

Analogía del Mundo Real

🗣️ Como hablar con un traductor experto

Imagina que tenés una biblioteca gigante (base de datos) con millones de libros, pero todos están catalogados en un idioma técnico complicado (SQL).

En lugar de aprender ese idioma, tenés un traductor experto (OpenAI) que:

  1. Escucha tu pregunta en español: "¿Cuántos libros hay de ciencia ficción?"
  2. La traduce al idioma técnico de la biblioteca (SQL)
  3. Busca la información en el catálogo
  4. Te responde en español: "Hay 127 libros de ciencia ficción"

¿Para qué sirve?

  1. Democratización de datos: Cualquiera puede consultar la base de datos sin saber SQL
  2. Rapidez: No necesitas escribir queries complejas
  3. Menos errores: La IA genera SQL correcto y optimizado
  4. Respuestas claras: Los resultados se presentan en lenguaje humano

Componentes del Sistema

Componente Descripción Tecnología
Frontend Interfaz donde el usuario escribe su pregunta HTML + JavaScript
HumanQueryController Controlador que recibe la pregunta y coordina el proceso ASP.NET Core
OpenAiService Servicio que se comunica con OpenAI OpenAI API (GPT-4)
SQL Server Base de datos donde se ejecutan las consultas Microsoft SQL Server
QueryLogService Servicio que registra todas las consultas para monitoreo In-Memory Storage

✅ En Resumen

Human Query convierte preguntas en lenguaje natural a consultas SQL, las ejecuta en la base de datos, y presenta los resultados en un formato fácil de entender para cualquier persona.

Las 3 Etapas del Proceso

Etapa 1: Traducción (Human → SQL)

El método HumanQueryToSqlAsync toma la pregunta del usuario y:

  • Obtiene el esquema completo de la base de datos (tablas y columnas)
  • Crea un prompt para OpenAI con el esquema y la pregunta
  • OpenAI genera una consulta SQL válida
  • Retorna el SQL en formato JSON: {"sql_query": "SELECT ..."}

Etapa 2: Ejecución (SQL → Resultados)

El método QueryDatabaseAsync:

  • Recibe la consulta SQL generada por OpenAI
  • La ejecuta contra SQL Server usando ADO.NET
  • Convierte los resultados en una lista de diccionarios
  • Maneja errores de SQL y retorna lista vacía si falla

Etapa 3: Humanización (Resultados → Respuesta Natural)

El método BuildAnswerAsync:

  • Toma los resultados crudos de la base de datos
  • Los envía a OpenAI junto con la pregunta original
  • OpenAI genera una respuesta en lenguaje natural
  • Ejemplo: "Hay 91 clientes en la base de datos"

⚠️ Consideraciones de Seguridad

  • El SQL generado no está sanitizado - confía en que OpenAI genera SQL seguro
  • No hay validación de permisos - cualquier usuario puede consultar cualquier tabla
  • Los errores de SQL se ocultan - podría generar respuestas incorrectas
  • Para producción: agregar validación de SQL, permisos por usuario, y auditoría

Flujo de Datos Completo Intermedio

Ejemplo: "¿Cuántos clientes hay?"

1. Usuario envía la pregunta

POST /api/HumanQuery/human_query
Content-Type: application/json

{
  "HumanQuery": "¿Cuántos clientes hay?"
}

2. Backend obtiene el esquema de la BD

-- Consulta INFORMATION_SCHEMA
SELECT TABLE_NAME FROM INFORMATION_SCHEMA.TABLES WHERE TABLE_TYPE = 'BASE TABLE'
SELECT COLUMN_NAME, DATA_TYPE FROM INFORMATION_SCHEMA.COLUMNS WHERE TABLE_NAME = @TableName

-- Resultado:
Customers(CustomerID nvarchar, CompanyName nvarchar, ContactName nvarchar, ...);
Orders(OrderID int, CustomerID nvarchar, OrderDate datetime, ...);
Products(ProductID int, ProductName nvarchar, UnitPrice money, ...);

3. Primera llamada a OpenAI (Generar SQL)

Prompt enviado a OpenAI:
---
Given the following schema, write a SQL query that retrieves the requested information.
Return the SQL query inside a JSON structure with the key "sql_query".

IMPORTANT: This is SQL Server, so:
- Always use square brackets [] around table names and column names

<schema>
Customers(CustomerID nvarchar, CompanyName nvarchar, ...);
Orders(OrderID int, CustomerID nvarchar, ...);
</schema>

User query: ¿Cuántos clientes hay?
---

Respuesta de OpenAI:
{
  "sql_query": "SELECT COUNT(*) as total FROM [Customers]"
}

4. Ejecutar SQL en la base de datos

-- SQL ejecutado:
SELECT COUNT(*) as total FROM [Customers]

-- Resultado:
[
  {
    "total": 91
  }
]

5. Segunda llamada a OpenAI (Humanizar respuesta)

Prompt enviado a OpenAI:
---
Given a user's question and the SQL rows response from the database,
write a human-readable response to the user's question.

<user_question>
¿Cuántos clientes hay?
</user_question>

<sql_response>
[{"total": 91}]
</sql_response>
---

Respuesta de OpenAI:
"Hay 91 clientes en la base de datos."

6. Respuesta final al frontend

HTTP 200 OK
Content-Type: application/json

{
  "success": true,
  "respuestaHumanizada": "Hay 91 clientes en la base de datos.",
  "sqlGenerado": "SELECT COUNT(*) as total FROM [Customers]",
  "resultadosCrudos": [
    {
      "total": 91
    }
  ]
}

HumanQueryController.cs - Endpoint Principal

1. Recepción de la solicitud

[HttpPost("human_query")]
public async Task<IActionResult> HumanQuery([FromBody] PostHumanQueryPayload payload)
{
    var stopwatch = Stopwatch.StartNew();
    var log = new QueryLog
    {
        Id = Guid.NewGuid(),
        Timestamp = DateTime.UtcNow,
        HumanQuery = payload.HumanQuery ?? string.Empty,
        Success = false
    };

    try
    {
        if (string.IsNullOrWhiteSpace(payload.HumanQuery))
        {
            log.ErrorMessage = "La consulta humana no puede ser vacía.";
            _logService.AddLog(log);
            return BadRequest(new { message = log.ErrorMessage });
        }

¿Qué hace?

  • Crea un log para registrar toda la operación
  • Inicia un cronómetro para medir el tiempo de ejecución
  • Valida que la pregunta no esté vacía

2. Obtener esquema de la base de datos

// Obtener schema
log.DatabaseSchema = GetSchema();

El método GetSchema():

private string GetSchema()
{
    using (var connection = new SqlConnection(_connectionString))
    {
        connection.Open();

        // Obtener todas las tablas
        var cmd = new SqlCommand(@"
            SELECT TABLE_NAME
            FROM INFORMATION_SCHEMA.TABLES
            WHERE TABLE_TYPE = 'BASE TABLE'
        ", connection);

        var reader = cmd.ExecuteReader();
        var tableNames = new List<string>();

        while (reader.Read())
        {
            tableNames.Add(reader.GetString(0));
        }

        reader.Close();

        // Para cada tabla, obtener sus columnas
        var schemaDescription = new StringBuilder();

        foreach (var tableName in tableNames)
        {
            schemaDescription.Append($"{tableName}(");

            var columnsCmd = new SqlCommand(@"
                SELECT COLUMN_NAME, DATA_TYPE
                FROM INFORMATION_SCHEMA.COLUMNS
                WHERE TABLE_NAME = @TableName
                ORDER BY ORDINAL_POSITION
            ", connection);

            columnsCmd.Parameters.AddWithValue("@TableName", tableName);

            var columnsReader = columnsCmd.ExecuteReader();
            var columns = new List<string>();

            while (columnsReader.Read())
            {
                columns.Add($"{columnsReader.GetString(0)} {columnsReader.GetString(1)}");
            }

            schemaDescription.Append(string.Join(", ", columns));
            schemaDescription.AppendLine(");");

            columnsReader.Close();
        }

        return schemaDescription.ToString();
    }
}

¿Qué hace?

  • Consulta INFORMATION_SCHEMA para obtener todas las tablas
  • Para cada tabla, obtiene todas sus columnas y tipos de datos
  • Genera una descripción de texto del esquema: Customers(CustomerID nvarchar, Name nvarchar);

3. Generar SQL con OpenAI

// Generar SQL
var (sqlQueryJson, promptSql) = await HumanQueryToSqlAsync(payload.HumanQuery);
log.PromptToGenerateSql = promptSql;

// Parse JSON response
var cleanedJson = CleanJsonFromMarkdown(sqlQueryJson);
var sqlQueryResult = JsonConvert.DeserializeObject<Dictionary<string, string>>(cleanedJson);

if (sqlQueryResult == null || !sqlQueryResult.TryGetValue("sql_query", out var sqlQuery))
{
    log.ErrorMessage = "La respuesta no contenía la consulta SQL.";
    _logService.AddLog(log);
    return BadRequest(new { error = log.ErrorMessage });
}

log.GeneratedSql = sqlQuery;

¿Qué hace?

  • Llama a OpenAI con el esquema y la pregunta del usuario
  • OpenAI retorna JSON con el SQL generado
  • Limpia el JSON (OpenAI a veces lo envuelve en markdown)
  • Extrae el SQL del campo sql_query

4. Ejecutar consulta SQL

// Ejecutar query
var result = await QueryDatabaseAsync(sqlQuery);
log.ResultCount = result.Count;
log.RawDataJson = JsonConvert.SerializeObject(result);

El método QueryDatabaseAsync():

private async Task<List<Dictionary<string, object>>> QueryDatabaseAsync(string sqlQuery)
{
    var results = new List<Dictionary<string, object>>();

    try
    {
        using (var connection = new SqlConnection(_connectionString))
        {
            await connection.OpenAsync();

            using (var command = new SqlCommand(sqlQuery, connection))
            {
                using (var reader = await command.ExecuteReaderAsync())
                {
                    while (await reader.ReadAsync())
                    {
                        var row = new Dictionary<string, object>();

                        for (int i = 0; i < reader.FieldCount; i++)
                        {
                            var columnName = reader.GetName(i);
                            var value = await reader.IsDBNullAsync(i) ? null : reader.GetValue(i);
                            row[columnName] = value;
                        }

                        results.Add(row);
                    }
                }
            }
        }
    }
    catch (Exception ex)
    {
        Console.WriteLine("Error ejecutando SQL generado:");
        Console.WriteLine(ex.Message);
    }

    return results;
}

¿Qué hace?

  • Ejecuta el SQL generado contra SQL Server
  • Convierte cada fila en un Dictionary<string, object>
  • Si hay error, lo registra y retorna lista vacía

5. Humanizar la respuesta

// Generar respuesta humanizada
var (answer, promptHumanize) = await BuildAnswerAsync(result, payload.HumanQuery);
log.PromptToHumanize = promptHumanize;

if (string.IsNullOrEmpty(answer))
{
    log.ErrorMessage = "No se pudo generar la respuesta humana.";
    _logService.AddLog(log);
    return BadRequest(new { error = log.ErrorMessage });
}

log.HumanizedAnswer = answer;
log.Success = true;

El método BuildAnswerAsync():

private async Task<(string response, string prompt)> BuildAnswerAsync(
    List<Dictionary<string, object>> result,
    string humanQuery)
{
    var systemMessage = $@"
        Given a user's question and the SQL rows response from the database,
        write a human-readable response to the user's question.
        <user_question>
        {humanQuery}
        </user_question>
        <sql_response>
        {JsonConvert.SerializeObject(result)}
        </sql_response>
    ";

    var prompt = $"{systemMessage}";
    var response = await _openAiService.SendPromptAsync(prompt);

    return (response, prompt);
}

¿Qué hace?

  • Envía a OpenAI: la pregunta original + los resultados de SQL
  • OpenAI genera una respuesta en lenguaje natural
  • Retorna la respuesta humanizada

6. Retornar respuesta al frontend

return Ok(new {
    success = true,
    respuestaHumanizada = answer,
    sqlGenerado = sqlQuery,
    resultadosCrudos = result
});
}
finally
{
    stopwatch.Stop();
    log.ElapsedMilliseconds = stopwatch.ElapsedMilliseconds;
    _logService.AddLog(log);
}

¿Qué hace?

  • Retorna un JSON con toda la información
  • En el finally, siempre guarda el log (aunque falle)
  • Registra el tiempo total de ejecución

⚠️ Manejo de Errores

El sistema tiene varios niveles de manejo de errores:

  • Si OpenAI no responde: retorna error 500
  • Si el JSON está mal formateado: retorna error 400
  • Si el SQL falla: retorna lista vacía y continúa (⚠️ podría generar respuesta incorrecta)
  • Todos los errores se registran en el log

💡 Tips para hacer mejores preguntas

  • Sé específico: "productos más caros" en lugar de "productos"
  • Menciona límites: "los 10 mejores clientes"
  • Usa nombres de tablas si los conocés: "de la tabla Orders"
  • Indicá ordenamiento: "ordenado por fecha"
